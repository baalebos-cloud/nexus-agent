# IMPORTANT #1: pinned below 5.0.0 — OpenCV 5.x removed cv2.CascadeClassifier
# from the Python bindings entirely (confirmed: it's gone from `dir(cv2)`
# in 5.0.0.93), which breaks our default zero-download face detector
# (src/osint/face_detection_backend.py:HaarCascadeDetector). Do not relax
# this upper bound without rewriting that detector against OpenCV 5.x's
# replacement API first.
#
# IMPORTANT #2: deepface (below) depends on plain `opencv-python`, which
# conflicts with opencv-python-headless if both end up installed — they
# share the same `cv2` import namespace and partially overwrite each
# other, breaking native submodules with a confusing "module 'cv2' has no
# attribute X" error. requirements.txt alone cannot prevent pip from
# installing a transitive dependency (opencv-python), so setup.sh removes
# it after install — see setup.sh and the README "Setup" section. Do not
# `pip install -r requirements.txt` directly without also running that
# script (or its uninstall step) afterward.
